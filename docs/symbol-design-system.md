# Circuit Canvas シンボル・キャンバス規則 v1

## 決定済みの基本原則

- シンボルは、入力を左、出力を右、電源を上、GNDを下に置く。
- 抵抗・コンデンサ・ダイオード等は、読み慣れた一般的な回路記号に寄せる。
- 機能ブロックは、まず空白の矩形を基本とする。名称とピンで役割を伝え、内部の機能イラストは後から任意で追加できる。
- 汎用ブロックは、機能ブロックと同じ枠・ピン配置の規則に従う。
- ズーム率によって表示する情報を増減させない。名称、ピン、接続、付箋を常に同じ意味で表示し、読みやすさは文字の最小サイズ・キャンバス操作で担保する。
- 付箋は自由配置とし、必要なときだけ引出し線で任意の回路上の位置へ関連付ける。

## 視覚トークン

実装時は色を固定値で散在させず、テーマ用トークンとして定義する。ライト／ダークモードは同じ意味のトークンを別の値で提供する。

| 要素 | 規則 |
| --- | --- |
| 標準線 | 2 pt。配線、シンボル外形、引出し線の基本線幅 |
| 強調線 | 3 pt。選択中のシンボル・配線・付箋に使う |
| 補助線 | 1 pt。グリッド、選択枠、付箋の関連付け候補に使う |
| 機能ブロックの角丸 | 8 pt。小さくしすぎず、部品記号との違いを出す |
| 汎用ブロックの角丸 | 8 pt。機能ブロックと共通 |
| 付箋の角丸 | 10 pt。ブロックとの区別を付ける |
| シンボル名 | 14 pt・Medium。縮小ズーム時も可読性を維持する |
| ピン名 | 12 pt・Regular。ピン数が多い場合も省略記号に置換しない |
| 付箋タイトル | 14 pt・Medium |
| 付箋本文 | 13 pt・Regular、最大3行を初期表示。全内容は選択時にインスペクタで編集する |

## ピン規則

| 項目 | 規則 |
| --- | --- |
| 形 | 塗りつぶし円。接続点であることを形でも伝える |
| 表示径 | 10 pt。実際のタップ／クリック可能領域は少なくとも32 pt、iPhone/iPadでは44 ptを目標とする |
| 左右ピン | 外形の左右端から外向きに伸ばす。複数ピンは上下に等間隔で並べる |
| 上下ピン | 電源を上、GNDを下。縦方向のピンも外向きに伸ばす |
| 既定の汎用ブロック | 左2・右2の計4ピン。必要に応じて上下および左右に追加できる |
| ピン名 | 接続の意味を優先して短く付ける。例: `VIN`、`VOUT`、`GND`、`CAN-H` |

## 状態表現

色だけに頼らず、線幅・輪郭・アイコンも併用する。選択状態は点滅させない。点滅は注意を奪い、長時間の編集やアクセシビリティに適さないためである。

| 状態 | 表現 |
| --- | --- |
| 通常 | 基本色・標準線 |
| 選択中 | アクセント色の強調線＋選択枠。シンボル、配線、付箋を同じ原則で扱う |
| 配線作成中 | 基本色の仮配線。始点ピンは選択枠、接続可能な終点は輪郭で示す |
| 未接続ピン | 注意色の外周リング。円そのものの形は維持し、接続後は通常表現に戻す |
| 付箋・未着手 | 種別アイコン＋通常の付箋面 |
| 付箋・実施中 | 種別アイコン＋細いアクセント色の帯 |
| 付箋・完了 | チェックマーク＋グレーアウト。本文、関連付け、出力情報は保持する |

## 付箋と引出し線

### 自由配置

- 付箋はキャンバス上の任意位置に置く。グリッドのスナップは任意で切替可能。
- 付箋の位置は回路要素の移動に自動追従しない。レイアウト意図を保つため、付箋自体も独立して移動できる。

### 関連付け

1. 付箋を**長押し**し、コンテキストメニューから**「関連付け」**を選ぶ。
2. キャンバスが関連付けモードになり、付箋から引出し線のプレビューを表示する。
3. シンボル、配線、ピン、またはキャンバス上の任意位置をタップ／クリックする。
4. 選択位置にアンカーを作り、付箋とアンカーを引出し線で接続する。

- 引出し線の終点は、関連先のシンボル・配線・ピンまたはキャンバス座標として保存する。
- 関連先のシンボル・配線が移動した場合、引出し線のアンカーは追従する。キャンバス座標へ関連付けた場合は固定位置を保つ。
- 付箋または関連先を削除する場合は、引出し線だけを削除するか、付箋も削除するかを明示して選べる。
- `Esc`、キャンセル、または選択ツールへの切替で関連付けモードを終了する。

## v1で描画する機能ブロック

DC/DC、MCU、CAN等の機能ブロックは、初期状態では名称のみの空白矩形にする。将来、シンボル定義に任意の内部アイコン／ラベル領域を追加できる構造にし、既存ドキュメントを壊さずに機能イラストを追加可能にする。
