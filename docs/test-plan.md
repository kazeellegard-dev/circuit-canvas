# Circuit Canvas v1 テストプラン

## 1. 目的と完了条件

v1が、3プラットフォームで「図を作る・編集する・保存する・共有する」という基本価値を安全かつ安定して提供できることを確認する。

リリース可否は、P0不具合が0件、P1不具合に回避策があること、受け入れテストと実機TestFlightの完了を条件とする。

## 2. テスト対象

- ドキュメントの新規作成、開く、保存、自動保存、複製、削除、復元
- シンボル配置・移動・回転・複製・削除・検索・プロパティ変更
- 実験メモの作成、対象への関連付け、状態変更、フィルタ、出力時の表示切替
- ピン接続、直交配線、経路編集、配線の削除・再接続
- パン、ズーム、グリッド、スナップ、選択、複数選択、Undo/Redo
- カスタムブロック、マイシンボル
- PDF/PNG出力、共有シート、Files/Finder、iCloud Drive同期
- iPhone、iPad、Macに固有の入力・レイアウト・キーボード操作
- アクセシビリティ、ローカライズ、性能、回帰、クラッシュ耐性

## 3. テストレベル

| レベル | 主な対象 | 自動化方針 |
| --- | --- | --- |
| Unit | データモデル、シリアライズ、配線計算、Undo/Redo、SVG/PDF変換 | Swift Testing/XCTestで必須 |
| Integration | ドキュメント入出力、iCloud Drive、共有、エクスポート | スタブ＋実機の両方 |
| UI | 配置・配線・選択・ショートカット・画面遷移 | XCUITestで主要フローを自動化 |
| 手動 | Pencil、複数ウィンドウ、Files/Finder、外部キーボード、VoiceOver | 実機チェックリスト |
| 探索的 | 初回利用時の迷い、誤操作、長時間利用 | TestFlight参加者と社内レビュー |

## 5. 実機マトリクス

| 種別 | 最低1台 | 重視する確認 |
| --- | --- | --- |
| iPhone | 小型または標準サイズの現行機 | 片手操作、ツールバー、表示密度、共有 |
| iPad | Apple Pencil対応の11インチ級 | ペン、指、Split View、横／縦、外部キーボード |
| iPad | 13インチ級 | 大キャンバス、サイドバー、ステージマネージャ |
| Mac | Apple silicon Mac | キーボード、トラックパッド、複数ウィンドウ、Finder |

OSはサポート対象の最小バージョンと最新バージョンの両方で確認する。ベータOSはリリース判定の対象外とし、次版の先行検証に使う。

## 6. 性能・信頼性の測定

| 指標 | 目標 | 測定条件 |
| --- | --- | --- |
| 新規空白ドキュメント表示 | 1秒以内を目標 | 実機・コールド起動後 |
| 1,000ノード文書の初回表示 | 3秒以内を目標 | 実機・ローカルファイル |
| パン／ズーム | 通常操作で視覚的な引っ掛かりなし | iPad実機、代表文書 |
| 自動保存 | UIをブロックしない | 大規模文書を連続編集 |
| クラッシュフリー率 | TestFlightで99.5%以上を目標 | 直近14日・十分な利用回数後 |

目標未達時は、レンダリングのキャッシュ、可視領域だけの描画、SVGの事前変換、差分保存を順に検討する。

## 7. TestFlight計画

1. **内部テスト**: 開発者・デザイナー。毎PRでUnit/UIテスト、週次で実機スモークテスト。
2. **クローズドベータ**: 5〜10名の対象ユーザー。代表課題を渡し、画面録画とアンケートで詰まりを収集。
3. **外部TestFlight**: 25〜50名。クラッシュ、継続利用、出力品質、プライバシー表記を確認。
4. **リリース候補**: App Storeメタデータ、スクリーンショット、サポートURL、プライバシー回答、復旧手順まで含めて審査用ビルドを確認。

AppleはTestFlightで内部・外部テスターを招待できる。詳細は[Appleの配布・提出ガイド](https://developer.apple.com/app-store/submitting/)を参照。

## 8. 不具合の優先度

- **P0**: データ消失、クラッシュ、保存不能、主要フロー不能、誤ったPDF出力、重大なアクセシビリティ阻害。リリース不可。
- **P1**: 重要機能の不便・性能低下・回避可能な破綻。原則修正、未修正なら既知の制限を明示。
- **P2**: 表示ずれや低頻度の軽微な問題。次回以降に計画する。
