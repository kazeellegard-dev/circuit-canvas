# Circuit Canvas v1 画面レイアウト・操作仕様

## 設計方針

「短時間で作図する」ことを最優先に、キャンバスを常に最大化する。編集対象の選択に応じて必要な情報だけを出し、固定パネルを増やしすぎない。

## iPad（横向き）の標準レイアウト

```text
┌──────────────────────────────────────────────────────────────────────────┐
│ Circuit Canvas   ↶ ↷  選択  配線  ＋シンボル  ＋メモ   共有  …          │
├───────────────┬──────────────────────────────────────────┬──────────────┤
│ シンボル      │                                          │ インスペクタ │
│ [検索]        │              無限キャンバス              │              │
│               │                                          │ 選択なし:   │
│ 最近使った    │    ┌──────┐              ┌──────┐       │ 図面設定     │
│ 電源・基準    │    │ DC/DC │──────────────│ MCU  │       │              │
│ 受動部品      │    └──────┘              └──────┘       │ 選択あり:   │
│ 機能ブロック  │                       ┌──────────┐       │ 属性／メモ  │
│ 通信          │                       │ 改造      │       │              │
│ センサー      │                       │ R12を変更 │       │              │
│               │                       └──────────┘       │              │
├───────────────┴──────────────────────────────────────────┴──────────────┤
│ 100%   グリッド  スナップ   選択数・未完了メモ数                         │
└──────────────────────────────────────────────────────────────────────────┘
```

- **上部ツールバー**: Undo/Redo、選択、配線、シンボル追加、メモ追加、共有、その他操作。主操作は常に1タップで開始できる。
- **左サイドバー**: 検索可能なシンボルライブラリ。狭い表示幅ではツールバーから開くポップオーバーに切り替える。
- **中央キャンバス**: パン・ズーム・選択・配置の主領域。グリッドとスナップを既定で有効にする。
- **右インスペクタ**: 未選択時は図面設定、選択時はシンボル／配線／付箋の属性を表示する。狭い幅ではボトムシートに切り替える。
- **下部ステータスバー**: ズーム、グリッド、スナップ、選択数、未完了実験メモ数を小さく表示する。

## MacとiPhoneへの適応

| プラットフォーム | レイアウト | 入力の最適化 |
| --- | --- | --- |
| Mac | iPadと同じ3ペインを基本に、左右のサイドバーは表示切替可能 | ショートカット、右クリック、ドラッグ、矢印キー移動 |
| iPad 縦向き | 左ライブラリをポップオーバー、右インスペクタをボトムシートへ | Apple Pencil／指の大きめヒット領域 |
| iPhone | キャンバスを全画面化し、ライブラリとインスペクタはボトムシート | 閲覧・軽微修正中心。タップでメモやシンボルを選択 |

## 実験メモの配置操作（確定）

### 任意位置への付箋配置

1. 上部ツールバーの **「＋メモ」** ボタンを押す。
2. キャンバスは**メモ配置モード**になる。カーソル／タッチ位置に付箋のプレビューを表示する。
3. 任意のキャンバス位置をタップまたはクリックする。
4. その位置に付箋を置き、右インスペクタ（iPhoneではボトムシート）で種別・タイトル・本文を入力する。
5. 保存後は選択ツールへ自動的に戻る。

### 配置モードのルール

- `Esc`（Mac／外部キーボード）またはツールバーの選択ツールでキャンセルできる。
- ドラッグ・ピンチは配置せず、パン・ズームとして機能する。誤配置を防ぐため、明確なタップ／クリック時だけ作成する。
- 付箋はグリッドにスナップするが、スナップをオフにした場合は任意座標に置ける。
- 付箋をシンボルまたは配線の近傍に置いた場合、作成後に「この対象に関連付ける」候補を表示する。ユーザーが選んだときだけ関連付ける。
- 付箋は配置後にドラッグで移動、タップ／クリックで編集、Deleteで削除できる。
- 完了は付箋上のチェックボックスまたはインスペクタから切り替える。完了時も配置と本文は残し、チェックマーク＋グレーアウトで表す。

## ツールバーの優先順位

| 操作 | 表示 | 目的 |
| --- | --- | --- |
| 選択 | 常時 | 通常操作へ戻る |
| 配線 | 常時 | ピンを接続する |
| ＋シンボル | 常時 | ライブラリを開き、配置モードにする |
| ＋メモ | 常時 | 任意位置に実験付箋を置く |
| Undo / Redo | 常時 | 誤操作をすぐ戻す |
| 共有 | 常時 | PDF/PNG/編集ファイルを渡す |
| その他 | 常時 | グリッド、整列、複製、出力設定等 |

## 受け入れ基準

- 初回利用者が、説明なしに「＋メモ」から任意位置へ付箋を配置し、本文を入力して完了にできる。
- シンボル・配線・付箋が混在しても、どのツールが有効かを色だけに頼らず判別できる。
- iPad横向きでは、標準的な編集でサイドバーを閉じずに作図・配線・メモ入力を完結できる。
