# Circuit Canvas v1 要件定義

## 1. 製品の範囲

### 目的

電気・電子システムの構成を、機能ブロックと基本回路記号を混在させ、実験・改造・測定のメモとともに、iPhone・iPad・Mac上で作成・編集・共有できるようにする。

### 非目標

- PCBレイアウト、ガーバーデータ、部品表、ERC/DRC
- SPICE等による電気シミュレーション
- リアルタイム共同編集
- 任意SVGの完全な編集機能
- Windows／Android／Web版

## 2. リリース対象とプラットフォーム方針

- SwiftUIを中心とするネイティブのユニバーサルアプリとする。
- iOS/iPadOS/macOSを同一App Store Connectレコード・同一Bundle IDのユニバーサル購入として配布する。
- iPadを主要編集端末、Macを詳細編集・出力端末、iPhoneを閲覧・軽微修正端末として最適化する。
- ローカルファイルを正とするドキュメント型アプリにする。初期からFiles／Finderで開く・保存する・共有する機能を提供する。
- iCloud Drive同期はv1の必須要件、CloudKit共有はv1.1以降の候補とする。

Appleは、複数プラットフォームのビルドを同一アプリレコードへ紐付けるユニバーサル購入を提供している。また、ドキュメント型アプリは`DocumentGroup`により自動保存、ファイル選択、ショートカット、競合解決等を利用できる。詳細は[Appleのユニバーサル購入説明](https://developer.apple.com/help/app-store-connect/create-an-app-record/add-platforms)および[ドキュメント型アプリの説明](https://developer.apple.com/documentation/swiftui/creating-a-document-based-app)を参照。

## 3. ユーザーストーリーと受け入れ条件

| ID | ユーザーストーリー | 受け入れ条件 |
| --- | --- | --- |
| US-01 | 利用者として、新しい図をすぐ始めたい | 空白、電源ツリー、MCU＋センサー、通信の4テンプレートから作成できる |
| US-02 | 利用者として、意味のある記号を置きたい | ライブラリ検索またはカテゴリからシンボルを配置し、名称・値・注記を編集できる |
| US-03 | 利用者として、ピン同士をつないで構成を表したい | ピンからピンへ線を作り、選択・削除・再配線できる。配線は直交を既定にする |
| US-04 | 利用者として、図を読みやすく保ちたい | グリッド、スナップ、ズーム、パン、整列、重なり順、複数選択を使える |
| US-05 | 利用者として、別の端末・相手に渡したい | 独自編集形式、PDF、PNGを保存・共有できる。iCloud Driveを介し同一Apple IDの端末間で更新できる |
| US-06 | 利用者として、繰り返し使うブロックを再利用したい | 汎用ブロックに任意数のピンを追加し、名称・説明を設定してマイシンボルとして保存できる |
| US-07 | Mac利用者として、効率よく編集したい | Command-S/Z/Shift-Z/A、Delete、矢印キー移動、コピー・ペースト、メニューからの主要操作を使える |
| US-08 | 実験者として、改造箇所・測定箇所・次の作業を図に残したい | 任意の位置・シンボル・配線にメモを添付し、状態と優先度を設定できる |
| US-09 | 共同作業者として、メモの意図を見落としたくない | メモは通常表示と「実験メモのみ」表示で確認でき、PDF/PNG出力に含めるか選べる |

## 4. シンボル仕様

### 種別

1. **電子部品**: 抵抗、コンデンサ、ダイオード、LED、トランジスタ、MOSFET、Op-Amp、GND等。慣用記号を優先。
2. **機能シンボル**: AC/DC、DC/DC、LDO、MCU、ADC/DAC、CAN、UART、I2C、USB、絶縁、モータードライバ、センサー等。外形＋接続ピン＋名称で統一する。内部の機能イラストは将来追加できるようにするが、v1では空白矩形を基本とする。
3. **汎用ブロック**: 任意の名称・説明・ピン構成を持つ矩形ブロック。

### v1の初期ライブラリ

まず次の20種を実装し、利用テスト後に約70種へ拡張する。

`GND`, `抵抗`, `コンデンサ`, `ダイオード`, `LED`, `N-MOSFET`, `Op-Amp`, `AC/DC`, `DC/DC`, `LDO`, `Battery`, `MCU`, `CAN`, `UART`, `I2C`, `Digital Isolator`, `DC Motor`, `Generic Sensor`, `Connector`, `Generic Block`

### データモデルの要件

- シンボルのSVG（または描画定義）とピン位置は分離する。
- ピンは一意ID、名称、方向、種別、ローカル座標を持つ。入力は左、出力は右、電源は上、GNDは下を既定とする。
- 配線は両端ピンID、経路点、表示属性を持つ。単なる見た目の線にしない。
- 実験メモは一意ID、本文、種別、状態、優先度、作成日時、対象（キャンバス座標／シンボルID／配線ID）を持つ。
- ドキュメントはバージョン番号を持つJSONベースの独自形式（例: `.circuitcanvas` パッケージまたはJSON）で永続化する。
- SVG/PDF/PNGは読み取り専用の出力形式として扱う。

## 5. 画面・操作要件

| 領域 | iPad | Mac | iPhone |
| --- | --- | --- | --- |
| キャンバス | Apple Pencil／指でパン・ズーム・選択 | トラックパッド／マウスで精密操作 | 閲覧、ズーム、限定編集 |
| ライブラリ | 左ペインまたはポップオーバー | 左サイドバー | モーダルシート |
| インスペクタ | 右ペインまたはボトムシート | 右サイドバー | ボトムシート |
| 配線 | ピンをタップして終点ピンをタップ | ドラッグ、クリック | ピンのタップ接続 |
| 選択 | 大きめのヒット領域と明確なハイライト | バウンディングボックス・複数選択 | 大きめのヒット領域 |
| 実験メモ | 上部ツールバーの「＋メモ」から配置モードへ入り、任意位置をタップして追加 | 上部ツールバーの「＋メモ」から配置モードへ入り、任意位置をクリックして追加 | 上部ツールバーの「＋メモ」から任意位置をタップして追加 |

### 実験メモ（v1の差別化機能）

メモは**付箋型**で図面上へ置けるほか、シンボルまたは配線へ関連付けられる。関連先を移動してもメモの関係を維持する。実験の履歴を残すため、完了したメモは削除を促さず、チェックマークとグレーアウトで区別する。

- 種別: `改造`, `測定`, `確認`, `未解決`, `注意`
- 状態: `未着手`, `実施中`, `完了`。完了は付箋のチェックマークとグレーアウトで表示する。
- 本文: 短いタイトルと複数行本文。例: 「R12を10 kΩへ変更して波形を再測定」
- 表示: 種別アイコンと状態で識別し、色だけに依存しない。未完了は読みやすい付箋、完了はチェックマーク付きのグレーアウトした付箋とする。ズーム率で情報量を変えず、名称・ピン・付箋の意味を常に一貫して表示する。
- フィルタ: 種別・状態で絞り込み、必要に応じて完了メモを非表示にできる。既定では完了メモも表示する。
- 出力: PDF/PNGに含めるか、共有用に隠すかを出力時に選べる。
- 配置: 「＋メモ」ツールで配置モードに入り、任意のキャンバス座標をタップ／クリックして作成する。作成後は通常の選択モードへ戻る。`Esc`または選択ツールでキャンセルできる。
- 関連付け: 付箋を長押しして「関連付け」を選び、任意のシンボル・配線・ピン・キャンバス座標をタップ／クリックする。付箋から対象へ引出し線を描く。

### 操作の品質基準

- ピンのタップ可能領域は、見た目より十分広くする。
- 選択状態はアクセント色と線幅で強調し、点滅させない。接続中の仮配線は基本色、未接続ピンは注意色の外周リングで強調する。
- 選択状態、接続候補、未接続ピン、エラーは色だけに依存せず形状・ラベルでも区別する。
- Undo/Redoは少なくとも50操作を保持する。
- 1,000ノード／1,500配線の読み込み、パン、ズームを実用的な速度で扱えることを性能目標とする。

## 6. 非機能要件

- **オフライン**: 作成・編集・ローカル保存・PDF/PNG出力はネットワーク不要。
- **アクセシビリティ**: VoiceOverラベル、Dynamic Typeに対応し、主要操作をキーボードだけで完了可能にする。
- **プライバシー**: v1でアカウント・広告・行動トラッキングを必須にしない。図面内容をサーバーへ送信しない。
- **信頼性**: 自動保存と、異常終了後の復元を提供する。ファイル破損時は元ファイルを上書きしない。
- **ローカライズ**: 初期言語は日本語・英語。内部IDと表示文字列を分離する。
