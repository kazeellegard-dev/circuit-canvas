## 失敗の詳細

### R1: 倍率カプセル「倍率 N%」がどの倍率でも画面に見えない（F5 未解決）

- 再現手順: アプリを起動する（100%）。または 175% / 50% / 250% にする。
- 実際の挙動:
  - 画面のどこにも「倍率 N%」が見えない（左上にも右上にも無い）。
  - ツールバーの倍率ボタンはアイコンだけ。
  - 100%・175%・50%・250% のすべてで確認した。
  - 修正前は左上にカプセルが見えていたため、右上へ移した結果、画面外に出ている。
- 期待する挙動: 右上に現在の倍率が常時見える。
- スクリーンショット: `ipad-retest-2026-09-21-zoom-label-missing.png`（リセット後の100%。ツールバーの下、キャンバス右上に何も表示されていない）
- 原因の推測（未検証）:
  - `ContentView.swift` の `editor` の `ZStack` に、`canvasSize` が 2400×1800pt の `canvasContent` が入っている。
  - このため `ZStack` の幅が 2400pt になり、倍率表示の `VStack`/`HStack { Spacer(); Label }` がその右端（画面の外）に寄っている。
  - 外側の `.frame(width: proxy.size.width...)` と `.clipped()` は、その後に適用されている。
- 修正方針の案: 倍率表示を `.overlay(alignment: .topTrailing)` で `GeometryReader` の枠（画面サイズ）に付ける。または、倍率表示の `VStack` に `.frame(width: proxy.size.width, height: proxy.size.height)` を指定する。
- 受け入れ条件: 50/100/175/250% のすべてで、右上に「倍率 N%」（現在の値）が見える。ズームやパンで位置が動かない。

| 倍率 | 画面上のキャンバス移動量（MCU で測定） | 判定 |

| 100% | 100pt（−165px, −165px） | 成功 |

| 50% | 100pt（−166px, −165px） | 成功 |
| 250% | 100pt（−166px, −165px） | 成功 |

- 修正前は 100%で約53%、175%で約37%、50%で約200%だった。
- 50%で 780,1000 → 40,300 の大きなドラッグを2回連続で行っても、キャンバスは消えず、左上に約200pt四方の領域が残ってクランプされた。
- 250%で右へ400pt、左へ650pt+300pt と大きくパンしても問題はなかった。右方向では、キャンバス左端が画面左端から約100pt内側まで入る余白を許容している。
- シンボル・付箋のドラッグ中に、キャンバス全体がパンすることはなかった。

### E. 初期配線（50%で Main MCU を上へ100pt）

- MCU は −165px（100pt）で移動した。
- 「Temperature → MCU」「24V → MCU」「MCU → CAN」の3本すべてが、MCUの対象ピンに接続されたまま追従した。取り残された端点はない。
- 修正前に取り残されていた Temperature 配線も追従した。
- 「24V → MCU」の配線は、24Vの右ピンが MCU 左ピンより右側にあるとき、直交の中継線が MCU 本体の下をくぐる見え方になる。これは配線ルーティングの仕様に起因する見た目で、今回の受け入れ条件外。

### F. ズームとリセット

- ピンチアウト（80pt→340pt間隔）で 250% に、ピンチイン（400pt→40pt間隔）で 50% に到達し、それ以上にはならなかった。
- 倍率ボタン（pt (742,54)）で、100%・初期位置に戻る（175% / 50% / 250% のすべてから確認）。
- 倍率の数値表示（「N%」）自体は見えないため、表示の内容は未確認（R1）。
