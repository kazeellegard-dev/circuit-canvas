## 詳細

### C: 経路（`00`〜`03`）

- 初期の 3 本: Temperature → MCU の配線が、約 12pt の折れ曲がり（ジョグ）で、24V の配線と縦線を分けている。ピンを共有する MCU 左ピンの近くだけが、合流。
- S1（Temperature 右 → CAN 左）: MCU の下を通り、CAN 左ピンへ左側から入る。
- S2（Temperature 右 → MCU 右）: MCU の下を通り、MCU 右ピンへ右側の外から入る。
- S3（24V 左 → MCU 左）: 24V の左へ回り込み、24V 本体の下を通って、MCU 左ピンへ入る。

### B: 同じシンボルのピン（`04`）

- 配線ツールで Temperature の右ピンを始点にし、同じ Temperature の左ピンをタップ: 配線は追加されず、始点の強調とヒント「終点のピンをタップ」が、そのまま残った。

### A: ヒント（`05`〜`07`）

- 175%（パンなし・パン後）、250%、50% のすべてで、ヒントは同じ大きさで、左上（倍率ラベルの反対側）に表示された。前回の指摘 H1（パンで画面外へ出る）は解消。

### D: 線分ドラッグ（`08`〜`10`）

- 100%: 24V → MCU の縦線を、30pt 左へドラッグ。縦線が x=275 → 245 に動いた（30pt）。水平の線分は、両側で伸び、両端はピンに接続したまま。
- 境界（`09`）: 同じ線分を MCU の方へ 100pt 右にドラッグすると、線分は MCU の左端（x=295）で止まり、本体の内部へは入らない。
- 175%（`10`）: 80pt のドラッグで、縦線が 79.8pt 動いた（ピクセル計測）。

### E: 交差の弧（`11`〜`13`）

- S3 の縦線を、24V の配線の縦線の右まで動かす（263 → 285）と、24V の配線の縦線が、S3 の横線を、右へ膨らむ小さな半円でまたいだ（`11`）。横線は途切れない。ご提示の参考画像と同じ向き。
- 元に戻すと、弧が消えた（`12`）。
- シンボルを動かしたあとの再計算でも、複数の交差に弧が付いた（`13`。50% の画面。操作の誤りでシンボルが動いた状態だが、弧の再計算の確認にはなった）。
- 合流（共有ピンの近く）には、弧は付かない。

### C3: 手動の位置の保持（`14`）

- 24V の配線の縦線を x=245 へ動かしたあと、Main MCU を 80pt 下へ動かした: 縦線は x=245 のまま、端だけが MCU のピンへ伸びた。Temperature → MCU、MCU → CAN の配線は、自動で再計算された。

## 観察（失敗にしない）

1. **S3 の経路が、24V 本体の下端にごく近い**（約 5pt）。本体の内部ではないが、見た目が窮屈。左へ 20pt 出て戻る折れ曲がりも、やや不自然。
2. **ピンを共有する配線の合流**は、T 字の分岐に見える（S1・S2 の終端付近）。仕様どおり（共有ピンに接する線分の重なり）。
3. **ピンチの指がシンボルや線分の上から始まると、ズームではなく、シンボルのドラッグになる**ことがあった（250% → 50% の縮小で、Main MCU が動いた）。今回の変更由来か、以前からの挙動かは、未確認。空白から始めれば、ズームになる。
4. 50% の画面では、縦線が近接して並ぶ箇所があり、弧が小さくて見分けにくい（`13`）。
