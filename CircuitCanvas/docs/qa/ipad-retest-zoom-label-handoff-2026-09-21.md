## 実施項目

コードは変更せず、各項目を「成功」「失敗」「確認不能」で記録すること。失敗時は、再現手順、実際の挙動、期待する挙動、スクリーンショットを添えること。

### 1. 右上の倍率表示（R1再確認）

1. アプリを起動する。
2. 表示が100%の初期状態で、キャンバス右上に `倍率 100%` が見えることを確認する。
3. ピンチ操作で50%、175%、250%へそれぞれ変更する。
4. 各倍率で右上に `倍率 N%` が見えることを確認する。
5. 各倍率でキャンバスをパンし、倍率ラベルが画面上の同じ右上位置に留まることを確認する。
6. 倍率リセットを実行し、100%・初期位置へ戻った後も `倍率 100%` が見えることを確認する。

受け入れ条件:

- 50% / 100% / 175% / 250% のすべてで、現在の倍率がキャンバス右上に常時表示される。
- パン／ズーム／リセットでラベルが画面外へ移動しない。

### 2. 付箋ドラッグの100%測定（前回未確認）

1. 倍率リセットを実行して100%へ戻す。
2. `R12を変更` の付箋を、画面上で水平または垂直に正確に100ptドラッグする。
3. ドラッグ前後のスクリーンショットから、付箋の画面上の移動量を測定する。
4. 付箋からの引出し線が追従していること、およびキャンバス全体がパンしていないことを確認する。

受け入れ条件:

- 付箋の画面上の移動量が100pt（±数pt）である。
- 引出し線が付箋に追従する。
- 付箋の操作中にキャンバス全体が移動しない。
