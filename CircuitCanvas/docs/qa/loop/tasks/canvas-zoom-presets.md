# タスク（第4弾 4E）: 倍率を選べるボタンに変更

## 要件

- ツールバーの倍率ボタン（今は押すと 100% に戻るだけ）を、倍率を選べるメニューに変える。候補: 25%, 50%, 100%, 150%, 200%。
- 選ぶと、キャンバスの中心（見えている範囲の中心）を保ったまま、その倍率になる。
- 現在の倍率がどれとも一致しない（ピンチ操作中など）場合でも、メニューは開ける。一覧のどれかを選べば、その倍率にきっちり揃う。

## 受け入れ条件（QA がこれで判定する）

1. 倍率ボタンを押すと、25/50/100/150/200% の一覧が出る。
2. 一覧から選ぶと、キャンバスがその倍率になる（右上の倍率表示にも反映される）。
3. ピンチで中間的な倍率（例: 73%）にしてから一覧を開いて 100% を選ぶと、100% にきっちり揃う。

## 対象外・注意

- ピンチ操作自体（0.5〜2.5倍の範囲）は変更しない。一覧は、その範囲に収まるきっちりした値のみ。
