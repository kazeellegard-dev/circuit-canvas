# タスク（第4弾 4C）: 編集モード（配線・シンボル・付箋の削除）

## 要件

- ツールバーに「編集」ボタンを追加する。押すと編集モードに入る。
- 編集モード中は、画面の左上に、編集モード中であることを常に強調して表示する（バッジ等）。
- 編集モード中は、シンボル・ブロック・付箋のそれぞれの右上に、✗ アイコンが出る。タップすると、「削除しますか？」の確認を出し、確定すると個別に削除する。
- 編集モード中は、配線をタップすると削除できる（確認は不要）。削除できる範囲は、タップした 1 区間（直線部分）のみ。配線の一部だけ消えて、どこにも繋がっていない配線が残る可能性があるが、今回はそのままでよい（後で対応）。
- 編集モード中は、連続して削除できる（1 回削除しても、モードは終了しない）。
- 編集モード中は、編集モードのボタン自体は常に押せる（強調表示）。他の機能のボタン（選択・配線・＋シンボル・＋メモ・倍率・確認・設定）は、グレーアウトして押せないようにする。編集モードのボタンを再度押すと、通常モードに戻る。

## 受け入れ条件（QA がこれで判定する）

1. 編集ボタンを押すと、編集モードに入り、左上に編集モード中の表示が出る。他のツールバーのボタンはグレーアウトする。
2. シンボル・付箋の右上に ✗ が出る。タップすると確認が出て、確定すると削除される。
3. 配線をタップすると、確認なしで、その区間だけ削除される。
4. 削除操作を続けて行える（モードから出ない）。
5. 編集ボタンを再度押すと、通常モードに戻り、✗ アイコンが消え、他のボタンが押せるようになる。

## 対象外・注意

- 配線の削除で生じる「どこにも繋がっていない配線」の扱いは、今回は対応しない。
- ピンの削除（3C で追加した機能）は対象外。
