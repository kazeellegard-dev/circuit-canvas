# タスク（第3弾 3C）: ブロックへのピンの追加

前提: 3B（汎用ブロック・アイコン）の後に着手する。

ユーザー決定（2026-09-27）: ピンを追加する操作は、「辺の空きスロットに＋が出る」。選択中のブロックの、まだピンのない段（スロット）に、＋のボタンが出て、タップすると、そこにピンが追加される。

## 背景

2A（`circuit-symbols-block-resize.md`）で、ブロックの高さは 30pt の倍数にし、1 段（30pt）ごとに、左右へ 1 ピンずつ追加できるスロット（y = 上端 + 15 + 30 × k）を、あらかじめ用意した。今回、そのスロットに、実際にピンを追加できるようにする。

## 要件

- `SymbolItem`（ブロックのみ）に、ピンの一覧を持たせる（今は、暗黙に「左右 1 個ずつ、最上段」だったものを、明示的なリストにする）。既定は、左右の最上段の 2 本（今と同じ見た目・座標）。
- 選択中のブロックの、**ピンのない段の、左右それぞれの位置**に、小さな＋ボタン（タップ領域 32pt 以上、ピンの丸・リサイズハンドルと重ならない位置）を出す。タップすると、その段・その辺（左または右）に、ピンが追加される。
- ピンの座標は、今の左右ピンと同じ考え方（辺の中央、段ごとに 30pt 間隔）。
- 追加したピンにも、識別子を付ける（`symbol-<title>-pin-N`。N はピンの追加順）。配線・削除・移動・拡大縮小・追従は、既存のピンと同じに扱う。
- ブロックの高さが、ピンの追加によって自動で増える必要はない（今回は、既存の段の空きスロットだけを対象にする。段が全部埋まっていれば、＋は出ない）。高さを増やす操作自体は、既存の拡大縮小（2A）で行う。
- ピンの削除は、今回は扱わない（追加のみ）。
- 配線の経路計算（`WireRouting`）は、2A で「ブロックの辺のどこにあるピンでも、外向きに引き出す」ように、すでに対応済み（`plannedRoute` の、段に関する分岐）。追加したピンでも、そのまま動くことを確認する。

## 受け入れ条件

| # | 操作 → 期待する結果 | UIテスト化 |
|---|---|---|
| N1 | 高さ 90（3 段）のブロックを選択すると、ピンのない段の左右に、＋が出る（最上段は、既にピンがあるので出ない）。 | する |
| N2 | ＋をタップすると、その位置にピンが追加され、`symbol-<title>-pin-2` のようなピンが現れる。座標が、その段・その辺の位置と一致する。 | する |
| N3 | 追加したピンから、配線を引ける。配線は、本体を通らず、外向きに引き出される。 | する |
| N4 | 追加したピンがある状態で、ブロックを大きくする（段を増やす）と、既存のピンの位置は変わらない。新しくできた段にも、＋が出る。 | する |
| N5 | 全ての段が埋まっている（左右とも、すべての段にピンがある）ときは、＋が出ない。 | する |
| N6 | 追加したピンも、削除・移動・拡大縮小・回転（ブロックは回転なしなので対象外）で、既存のピンと同じに追従する。 | する（既存の性質の再確認） |

## 仮定
- 1 つの段に、左右それぞれ、最大 1 本（左右で計 2 本）。
- ピンの名前（`pinSpecs` の `name`）は、「左ピン」「右ピン」のままでよい（段ごとの区別は、座標で行う）。
- 初期データの 4 つのブロックには、追加のピンは、最初から置かない。


## 更新（2026-09-27・実装時に判明・Codex レビュー対応）

「タップ領域 32pt 以上」と「ピンの丸・リサイズハンドルと重ならない」は、30pt の段の間隔の上では、**両立しない**ことが分かった（32pt の領域は、隣の段のピンと必ず重なる）。

- ＋ボタンは、**キャンバス座標で固定 26pt**（画面の拡大縮小に合わせて、ピンや段の間隔と同じ比率で、一緒に縮小・拡大する。他のボタン（回転・関連付け・リサイズハンドル）のように、画面上で常に32pt を保つ、拡大縮小しない方式ではない）。
  - 26pt なら、隣の段のピン（28pt）とも、辺の外側のリサイズハンドル（本体の外側にしか出ない）とも、どの倍率でも重ならないことを、計算で確認済み（下記のテストで検証）。
  - 32pt に届かない点は、意図した妥協（30pt の段の間隔という制約による）。
- ＋ボタンは、ピンの位置（辺の真上）から、少し外側にずらして置く（見分けやすくするため）。
- ブロックの縮小は、追加したピンのうち、いちばん下の段より低くはできない（そのピンの行き場がなくなるため）。「元の大きさに戻す」も、同様に、最小の高さを下回らない。
