# タスク（第5弾 5C）: 「テキスト」の追加（新しいシンボル種別）

2026-09-29 のユーザーフィードバックより。

## 要件

- ライブラリに、新しいカテゴリ「テキスト」タブを追加する。
- テキストは、シンボルのようなピン情報を持たない（配線できない）。
- タップして配置し、選択してドラッグで移動できる（シンボル・付箋と同様）。
- インスペクタから、内容（文字）を編集できる（付箋と同様）。
- 削除は、編集モードの✗、インスペクタの削除ボタン、Undo/Redo の対象にする（シンボル・付箋と同様の扱い）。

## 対象外・注意

- 回転・拡大縮小・アイコンは対象外（まずは文字のみのシンプルな要素）。
