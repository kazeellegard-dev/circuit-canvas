# タスク: 最低 OS を iPadOS 18 に下げる（2026-10-03 の利用者の要望）

## 背景

利用者の手元にある実機は、iPad 第 7 世代だけで、iPadOS 18 までしか対応していない。これまでの最低 OS は、iPadOS 26.5 だったため、そもそもインストールできなかった。iPadOS 18 で使えるようにして、使ってもらえる端末の幅を広げる。

## 要件

1. iOS の最低 OS（`IPHONEOS_DEPLOYMENT_TARGET`）を、26.5 から 18.0 に下げる。
   - macOS と visionOS の最低 OS は、変えない。
2. iPadOS 26 でしか使えない API を、使わない。ビルドで確認する（エラー 0 件）。
3. iPad 第 7 世代の画面（10.2 インチ、キャンバスの表示範囲は 810×825pt）で、次のことを満たす。
   - ツールバーのボタンが、すべて収まる。
   - 倍率のパネル（スライダー）が、画面に収まる。
4. **UI テストを、画面の大きさに左右されない書き方にする:**
   - 画面の外を指す座標（y=850〜906 など）を使わない。
   - キャンバスの要素の大きさに対する割合で、位置を指定しない。iPadOS 18 では、XCUITest がキャンバスの要素を、画面に見えている範囲ではなく、キャンバス全体（2400×1800）として報告するため。位置は、`viewport-size` を基準にする。
5. Info.plist の変更（Xcode による書き換え）を、そのまま取り込む。意味は同じで、「その場で開く」の設定（`LSSupportsOpeningDocumentsInPlace`）が、ビルド設定に移っただけ。

## 受け入れ条件

- I1: 最低 OS を 18.0 にした状態で、エラーなくビルドできる。
- I2: iPadOS 26.5 のシミュレータ（ゲートで使う端末）で、フルスイートが成功する。
- I3: iPad 第 7 世代（iOS 18.6）のシミュレータで、小さな画面のために失敗していたテストが成功する（下の 2 件を除く）。
  - 回路記号を並べる、配線の線分のドラッグ（2 件）、グリッドへの配置、関連付けの解除、操作のヒント、ほか
- I4: 実機の iPad 第 7 世代（iPadOS 18.3.2）に、インストールして起動できる。

## iOS 18 のシミュレータでの、XCUITest の既知の制約（アプリの不具合ではない）

次の 2 つは、XCUITest が合成するタップやドラッグが、アプリまで届かない現象です。アプリそのものは、正しく動くことを、人の操作（シミュレータをマウスで操作）で確認しました（2026-10-03）。

| 現象 | 起きるシミュレータ | 人の操作で確認した結果 |
|---|---|---|
| 配線の線分のドラッグが、動かない | iPad Pro 11 インチ（M4）、iOS 18.6 | iPad 第 7 世代（iOS 18.6）で、線分を直接ドラッグすると動く |
| 編集モードで、グループの削除ボタンが反応しない | iPad 第 7 世代、iOS 18.6 | マウスでクリックすると、「削除しますか？」が表示され、削除できる |

- どちらも、今回の変更より前のコードでも、同じように起きる。
- iPadOS 26.5 のシミュレータでは、どちらのテストも成功する。
- ゲートは、iPadOS 26.5 のシミュレータで実行する。そのため、これらのテストも、ゲートでは通常どおり実行する。

## 対象外

- iOS 18 のシミュレータでの、上の XCUITest の制約の回避
- iPhone での表示の最適化
