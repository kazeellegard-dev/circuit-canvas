# タスク（第5弾 5A）: ツールバー・キャンバスの使い勝手改善

2026-09-29 のユーザーフィードバックより。小粒な改善をまとめて扱う。

## 要件

1. **編集モード（削除）のアイコン**: ゴミ箱アイコンが他のツールバーアイコンと並ぶと違和感があるため変更する（案: `eraser` / `eraser.fill`）。並び順も、インスペクタ（「確認」）ボタンのすぐ左に移動する。
2. **＋シンボルボタン**: 押したときに、ライブラリのカテゴリタブを「選択中のシンボル」のカテゴリに自動で切り替える（今どのシンボルが選択されているか、タブを見ればわかるようにする）。また、カテゴリタブ・シンボル項目の選択中の色味が薄いので、はっきりわかるように強める。
3. **倍率変更**: ツールバーのメニュー（アイコン）を廃止し、代わりにキャンバス右上に常時表示している「倍率 100%」のラベルをタップするとメニューが開くようにする。
4. **付箋の初期状態**: 新規付箋の既定を、種別＝メモ、アイコン＝メモ（種別に連動する既定アイコン）にする。
5. **付箋のインスペクタへの近道**: 付箋を選択中、関連付けボタンの横に、インスペクタを直接開く（編集）ボタンを追加する。
6. **付箋の本文の改行**: 本文が改行できない（Return で編集終了になってしまう）。複数行・箇条書きが書けるよう、改行可能にする（`TextEditor` に置き換えるなど）。
7. **キャンバスの有効範囲**: どこまでが有効なキャンバスなのか見た目でわからない。色などで、有効範囲の内外がわかるようにする。
8. **キャンバスの初期表示位置**: 起動時にキャンバスの中央が見えるようにする（今は左上が起点）。

## 対象外・注意

- 二本指パン・パン専用モードは別タスク（5B）で扱う。
- テキスト（新しいシンボル種別）・インスペクタでのキャンバス直接編集・グループ化は、それぞれ別タスク（5C・5D・5E）。

## 更新（2026-09-29・実装時に判明）

要件8（起動時の中央表示）は、**アプリ起動直後ではなく、設定のリセット直後にのみ適用する**（中央表示そのものは実装済み）。

理由: 初期データ（サンプル回路の4シンボル・配線・付箋）は、キャンバス全体（2400×1800）の左上寄りの領域に配置されている。起動直後に単純にキャンバス中央（1200,900）へ表示位置を合わせると、サンプル回路が画面外に出てしまい、何も見えない状態で起動することになる。また、既存の自動テスト（90件以上）の多くが「起動直後は倍率100%・オフセット0」を前提に、画面上の絶対座標を直接検査している。起動直後の中央表示は、その前提を壊し、対象の書き直しが必要になる規模の変更になる。

「書きやすいように」という狙いに対しては、まっさらな状態（設定のリセット直後）でキャンバス中央を表示すれば十分に満たせると判断し、そちらのみ実装した。起動直後の中央表示が必要な場合は、初期データの配置替え（と、それに伴う既存テストの座標の書き直し）を伴う、別途の作業として扱う。
