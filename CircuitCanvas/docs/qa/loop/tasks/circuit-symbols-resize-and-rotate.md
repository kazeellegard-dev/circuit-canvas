# タスク: 回路記号の縮小・引き出し線の短縮・回転機能・電源系の縦向き

## 背景

`circuit-symbols` の画面確認（`CircuitCanvas/docs/qa/circuit-symbols-desktop-verify-2026-09-26.md`）に対する、ユーザーのフィードバック:

1. 追加になった回路記号は、**引き出し線が長すぎる。今の半分**にする。
2. 記号自体が**大きすぎる**。iPad ではまだよくても、iPhone などでは、すぐに画面がいっぱいになる。**少なくとも今の 2/3 くらいのサイズ**にする。
3. **記号の回転機能**を追加する。電源や GND が横向きなのは違和感しかない。
4. **電源系は、デフォルトを縦向き**にする。

## 現状の実装（参考）

- 回路記号（`CircuitSymbol.swift` の種類）は、シンボル中心の左右 ±75pt にピン（`-pin-0` が左、`-pin-1` が右）を持つ。1 端子の記号（GND・VCC）は、左のピンだけ。記号の本体（絵）は、中心付近で幅約 50pt。ピンから本体まで、片側約 50pt の引き出し線を描く。
- 配線の経路計算では、記号の本体を、幅 150 × 高さ 64 の長方形として扱う（`ContentView.swift` の `bodies`）。ピンの位置は `pins(for:)`。経路は、左のピンから左へ、右のピンから右へ、24pt 以上引き出す（`WireRouting.route`）。
- ブロック図型のシンボル（`24 V → 5 V`・`Main MCU`・`CAN`・`Temperature`・`DC/DC`・`MCU`・`CAN`・`センサー`・`汎用ブロック`）は、従来の見た目（幅 150 × 高さ 64、ピンは ±75pt）。
- インスペクタ（`ContentView.swift` の `inspector`）に、シンボルの名称・接続・削除がある。

## 要件（Codex）

- **対象は、回路記号型のシンボルだけ。** ブロック図型のシンボル（初期の 4 つと、`DC/DC`・`MCU`・`CAN`・`センサー`・`汎用ブロック`）の見た目・大きさ・ピンの位置・識別子は、**変えない**。既存のテストのうち、ブロック図型を対象とするものは、変更しない。
- **回路記号の大きさを、2/3 にする。**
  - 全体の大きさ（配線の経路計算で使う本体の長方形）を、横向きで、幅 100 × 高さ 44 程度にする（今の 150 × 64 の 2/3）。ピンは、中心の ±50pt。
  - 引き出し線（ピンの丸から、記号の本体の端まで）は、今の半分（約 25pt。25〜30pt でよい）にする。
  - 記号の本体の絵は、幅 44pt 以下にする。ラベル（名前）の文字の大きさは、読める範囲で、今のままか、少し小さくしてよい。
  - ピンの丸（直径 10pt）と、ピンのタップ領域は、今のままにしてよい（ただし、2 つのピンのタップ領域が重ならないこと）。
- **回転機能を追加する。**
  - 回転は、90° 単位（0° / 90° / 180° / 270°、時計回り）。反転は不要。
  - シンボルは、回転の角度を持つ。回転は、シンボルの中心を軸にする。回転しても、シンボルの位置（中心）は変わらない。
  - 回転の操作は、次の 2 つを用意する。
    1. インスペクタの、「回転」ボタン（1 回タップするごとに、90° 時計回り）。
    2. キャンバス上で、選択中のシンボルのそばに、小さな回転ボタン（円形の矢印。タップ領域は 32pt 以上。ピンのタップ領域と重ならない位置）。
  - 回転すると、ピンの位置・引き出しの向き・本体の長方形（縦向きなら 44 × 100 程度）が、回転後のものになる。配線は、自動で再計算される。手動で動かした線分（`manual`）は、その記号に接続している配線に限り、リセットして、自動の経路に戻してよい。
  - **経路計算を、上下方向の引き出しにも対応させる。** ピンごとに、外向きの方向（左・右・上・下）を持たせ、引き出しの最小長さ（24pt）・本体からの間隔（12pt）・重なりの回避・線分ドラッグ・交差の弧・分岐の黒丸などの既存の性質を、上下方向にも保つ。ピンの位置と、本体の長方形は、回転後のものにする。
  - ブロック図型のシンボルには、回転は適用しない（回転ボタンは表示しない。または、押せない）。
  - ラベル（名前）と、記号内の文字（M・V・A など）は、回転しても、**横書きのまま**（読める向き）にする。ラベルの位置は、縦向きのときは、記号の右側にしてよい（ピンの丸・引き出し線・配線と、重ならない位置）。
- **電源系のデフォルトを、縦向きにする。** 配置した直後の、デフォルトの向き:
  - 直流電源・電池: ＋が上、−が下（極板は水平）。ピンは、上と下。
  - 交流電源: 縦向き（ピンは、上と下）。
  - GND: ピンが上、3 本線が下（標準のアース記号）。1 つだけのピンは、上。
  - VCC: ピンが下、棒が上。1 つだけのピンは、下。
  - それ以外（受動部品・半導体・スイッチ・保護・負荷・その他）は、横向き（回転 0°）のまま。
  - 電源系の記号は、90° 単位で回転して、横向きにもできる。
- ライブラリの項目の絵は、デフォルトの向き（電源系は縦向き）で表示する。
- **識別子:** `symbol-<title>`、`symbol-<title>-pin-N`（`-pin-0`、`-pin-1`）は、そのまま。ピンの `accessibilityValue`（`x,y`）は、回転後の座標にする。回転の角度を、テストから確認できるようにする（例: `symbol-<title>-rotation` の `accessibilityValue` に `0` / `90` / `180` / `270`）。回転ボタンにも識別子を付ける（例: インスペクタは `inspector-rotate`、キャンバス上は `symbol-<title>-rotate`）。
- **テスト:** 前回の回路記号のテストのうち、大きさ・ピン位置（±75）・横向きを前提とするものは、新しい仕様に合わせて更新してよい。ただし、性質（本体の内部を通らない、重ならない、追従、ピン数、削除、同じシンボルの左右ピンは結べない、など）は、弱めない。`xcodebuild test` を実行して、すべて成功させてから完了する。

## 仮定（実装で迷ったらこれに従う。違うなら handoff に「要確認」と書く）

- ブロック図型のシンボルは、大きさを変えない（初期データとテストの前提のため）。iPhone での大きさは、ブロック図型については、別の機会に扱う。
- 回転の中心は、シンボルの中心。回転後の本体の長方形は、縦向きなら 44 × 100（横向きの 100 × 44 を、90° 回したもの）。
- ピンの外向きの方向: 0° は、`-pin-0` が左向き・`-pin-1` が右向き。90° は、`-pin-0` が上向き・`-pin-1` が下向き。180° は、`-pin-0` が右向き・`-pin-1` が左向き。270° は、`-pin-0` が下向き・`-pin-1` が上向き。
- 1 端子の記号（GND・VCC）は、`-pin-0` だけ。GND のデフォルトは 90°（ピンが上）。VCC のデフォルトは 270°（ピンが下）。直流電源・電池は、＋を `-pin-0` 側にして、デフォルトは 90°（＋が上）。
- 回転を、元に戻す（取り消す）操作は、今回は扱わない（4 回タップで一周する）。

## 対象外・注意

- 反転（鏡像）、45° 単位の回転、回転のジェスチャー（二本指）は、今回は扱わない。
- 3 端子以上の記号（トランジスタ・FET・オペアンプ・リレー・ロジックゲート）は、次のタスクとする。
- 配線の削除・選択、ピンの種類（入力/出力）の判定は、今回は扱わない。
- 初期データ: シンボルは 24V→5V (120,160) / Main MCU (370,250) / CAN (620,250) / Temperature (120,390)、配線は 3 本。アプリを再起動すると初期状態に戻る。
- 実機・iPhone のシミュレーターは対象外（iPad Pro 11-inch (M5) / iOS 26.5 シミュレーターのみ）。
