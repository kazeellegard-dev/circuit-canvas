# タスク（第5弾 5E）: グループ化機能

2026-09-29 のユーザー提案・仕様、および QA 回答（2026-09-29）より。

## 要件

- 専用アイコンをタップすると「グループ化範囲選択モード」に入る。
- そのモードでドラッグすると、四角い枠でドラッグ範囲を選択する。矩形に**一部でも重なった**シンボル・付箋・テキストが、グループ化対象として強調色（または点滅）になる。
- ドラッグを離すと「グループ化しますか？」を表示。「はい」でグループ化する。
- グループ化されたものをタップすると、グループの範囲全体が強調色になる（グループ単位で選択される）。
- グループは、まとめて移動できる（メンバーのどれかをドラッグすると、グループ全体が動く）。
- 編集モードでは、グループ単位でのみ削除できる（メンバー個別の削除は不可）。
- グループのメンバーは、個別編集（シンボルの移動・拡大縮小・回転・配線のつなぎ替えなど）ができない。
- グループ化されたメンバーと、グループ外のシンボルが配線でつながっている場合、配線はつながったまま、グループ外側の区間だけ、グループの移動に合わせて自動で再描画する。
- **グループの解除**: グループを選択中に、専用の「グループ解除」ボタンを表示する。押すと、グループが解除され、メンバーは個別に扱えるようになる。
- **入れ子は作らない**: 既存のグループのメンバーを含む範囲を、あらためてグループ化選択した場合、新しいグループを作る（グループの中にグループを作る）のではなく、既存のグループの範囲を広げる（対象を追加する）扱いとする。2つの既存グループにまたがって選択した場合も、1つのグループに統合する。

## 対象外・注意

- グループの入れ子は、今回は作らない（上記の通り、常にフラットな1段のグループとして扱う）。
- Undo/Redo の対象に含める（グループ化・グループ解除・グループごとの移動・削除も、他の操作と同様に扱う）。
