# タスク（第3弾 3A）: 付箋の拡大縮小・関連付けの操作性・インスペクタの整理

ユーザー決定（2026-09-27）:
- 関連付けは「辺の空きスロットに＋」ではなく（それはブロックのピン追加の話）、**選択中の付箋のそばに出る、キャンバス上のボタン**に変更する。回転ボタン（`symbol-<title>-rotate`）と同じ考え方。
- インスペクタは、確認・状態表示・名称や本文などの編集だけにする。操作（回転・関連付け）は置かない。

## 見つけている不具合（このタスクで直す）

**インスペクタの「関連付けを開始」ボタンが機能しない。** `linkingNote = id` を設定するだけで、インスペクタのシート（`showInspector`）を閉じていない。シートが画面を覆ったままなので、その下のキャンバスをタップできず、関連付けを完了できない。ユーザー報告「インスペクタからだとたどり着けない」の原因。

## 要件

### 1. 付箋の拡大縮小
- 選択中の付箋に、ブロックと同じ、四隅のハンドル（`symbol-<title>-resize-<corner>` に相当する識別子。付箋は `experiment-note-<title>-resize-<corner>` などとする）を出す。反対側の角を固定して、大きさが変わる。
- 大きさの範囲・刻みは、ブロック（`BlockSize`）と同じ考え方を流用してよい（最小・最大・刻みの値は、付箋の内容が収まる範囲で、実装時に決めてよい。目安: 幅 140〜400、高さ 80〜320、20pt 刻み）。
- 本文の文字は、大きさに応じて折り返す（今も `axis:.vertical` 相当で複数行）。小さくしすぎて文字が全く見えない、ということがないよう、最小値を決める。
- 大きさの情報は、`NoteItem` に持たせる（`size: CGSize`）。既定値は、今の見た目（幅 170、内容に応じた高さ）に近い値にする。
- ハンドルは、付箋のドラッグ・関連付けの線を妨げない。

### 2. 関連付けを、キャンバス上のボタンに
- 付箋を選択すると、そのそばに、丸いボタン（`arrowshape.turn.up.right` のアイコン。タップ領域 32pt 以上）が出る。タップすると、`linkingNote` が今の付箋になり、キャンバスをタップして、引き出し線の先（アンカー）を置ける（今の「関連付けたい位置をタップ」のヒントは、そのまま使う）。
- 位置は、回転ボタンと同じように、付箋の角の外側（重ならない位置）に置く。
- 長押しのコンテキストメニューの「関連付け」は、残してよい（サブの経路として）。
- インスペクタから、「関連付けを開始」ボタンを削除する。

### 3. インスペクタから、操作系のボタンを削除
- **回路記号の「回転」ボタンを、インスペクタから削除する**（`inspector-rotate`）。キャンバス上の回転ボタン（`symbol-<title>-rotate`）は、そのまま残す。
- インスペクタの、シンボルの項目には、名称の編集・接続状態の表示・（ブロックなら）大きさの表示とリセット・削除、だけが残る。
- 付箋の項目には、種別・タイトル・本文・完了・削除、だけが残る（関連付けの開始ボタンを除く）。

## 受け入れ条件

| # | 操作 → 期待する結果 | UIテスト化 |
|---|---|---|
| S1 | 付箋を選択すると、四隅にハンドルが出る。ドラッグすると、反対側の角を固定して、大きさが変わる。 | する |
| S2 | 大きさを変えても、本文が読める（折り返される）。範囲・刻みを守る。 | する（範囲・刻み）+ QA（見た目） |
| S3 | 付箋を選択すると、関連付けのボタンが出る。タップしてキャンバスをタップすると、引き出し線が付く。既存の「関連付けたい位置をタップ」のヒントが出る。 | する |
| S4 | インスペクタに、`inspector-rotate` と「関連付けを開始」がない。 | する |
| S5 | 長押しの「関連付け」は、引き続き動く。 | する（既存テストの再確認） |
| S6 | 回路記号の回転は、キャンバス上のボタンと、既存の性質（ピン追従・配線再計算）を保つ。 | する（既存テスト） |

## 仮定
- 付箋の大きさのハンドルは、ブロックの実装（`BlockSize` の考え方、`ResizeCorner`）を、付箋用に流用・共通化してよい。
- 付箋の大きさは、`NoteItem` にだけ影響し、回路図側（シンボル・配線）には影響しない。
