# タスク（第2弾 2B）: 3 端子以上の回路記号（トランジスタ・MOSFET・オペアンプ・ロジックゲート・リレー・コネクタ）

分担: 実装・テスト実行 = Claude、レビュー = Codex（`scripts/review-loop.sh --task このファイル`）。
順序: 第2弾は **このタスク（2B）を先に**、次に `circuit-symbols-block-resize.md`（2A）。ユーザー決定（2026-09-26）。

## 背景

第1弾（`circuit-symbols`、`circuit-symbols-resize-and-rotate`）は、2 端子（と 1 端子）の記号だけを扱った。ピンの仕組みが「中心の ±50pt の 2 点」に固定されているため、3 端子以上は、仕組みの拡張が必要。

## 追加する記号（ユーザー決定: 基本の半導体 + ロジックゲート・リレー・コネクタ）

| 種類 | ピン（0° のとき、中心が原点、y は下向き。名前: 座標 → 外向き） | カテゴリ |
|---|---|---|
| NPN トランジスタ | B: (-50,0) 左 / C: (25,-50) 上 / E: (25,50) 下 | 半導体 |
| PNP トランジスタ | 同上（矢印の向きだけ逆） | 半導体 |
| N-ch MOSFET | G: (-50,0) 左 / D: (25,-50) 上 / S: (25,50) 下 | 半導体 |
| P-ch MOSFET | 同上（矢印の向きだけ逆） | 半導体 |
| オペアンプ | IN+: (-50,-25) 左 / IN−: (-50,25) 左 / OUT: (50,0) 右（電源ピンは、今回は省く） | 半導体 |
| AND / OR / NAND / NOR / XOR | IN1: (-50,-25) 左 / IN2: (-50,25) 左 / OUT: (50,0) 右 | ロジック（新設） |
| NOT（インバータ） | IN: (-50,0) 左 / OUT: (50,0) 右 | ロジック |
| リレー | コイル A: (-25,-50) 上 / コイル B: (-25,50) 下 / COM: (25,-50) 上 / NO: (25,50) 下 | リレー・コネクタ（新設） |
| コネクタ（4 ピン） | P1〜P4: (-50,-75)(-50,-25)(-50,25)(-50,75) すべて左 | リレー・コネクタ |

- 座標は、25pt の格子に載せた「仮置き」。絵を描いて、不自然なら、格子の範囲で調整してよい（handoff に書く）。
- 本体の長方形（配線が通らない範囲）は、0° で、トランジスタ・MOSFET・リレー・オペアンプ・ゲート = 幅 100 × 高さ 100、コネクタ = 幅 50 × 高さ 150（右側に本体、ピンが左）。90°/270° では、幅と高さを入れ替える。
- 追加は、13 種類（半導体 5 + ロジック 6 + リレー 1 + コネクタ 1）。既存の 28 種類の見た目・識別子は、変えない。

## 要件

### 実装（Claude）
- **ピンの仕組みを、一般化する。** 各種類が、ピンの一覧（名前・0° のときの座標・外向きの方向）を持つ。`pinCount`・`pins(at:rotation:)`・`direction(for:rotation:)`・`body(at:rotation:)` は、この一覧から計算する。既存の 2 端子・1 端子の記号は、同じ値を返す（テストで保証する）。
- 回転（0/90/180/270）は、ピンの座標・外向きの方向・本体の長方形に、正しく反映される（時計回り、中心が軸）。
- 配線: 既存の性質（引き出し 24pt・本体の内部を通らない・重ならない・線分ドラッグ・交差の弧・黒丸・フォールバック）を、3 端子以上でも保つ。本体が大きい（100 以上）ので、`WireRouting.routingBounds` の余白の決め方（今は幅 50 のとき 24、他は 20）を、見直す。
- 同じシンボルの 2 つのピンは、結べない（今の規則を、「同じシンボルの任意の 2 ピン」に一般化）。
- ピンのタップ領域: 隣り合うピン（間隔 50pt）で、重ならない。`nearestPin` は、最も近いピンを選ぶ。
- ピンの `accessibilityLabel` に、名前（B / C / E / IN+ など）を含める。記号の中に、ピン名を、横書きの小さな文字で描いてよい（読める範囲。任意）。
- ライブラリ: 「半導体」に、トランジスタ・MOSFET・オペアンプを、新カテゴリ「ロジック」にゲート、新カテゴリ「リレー・コネクタ」に、リレー・コネクタを、入れる。ライブラリの絵は、デフォルトの向きで表示する。
- 識別子: `symbol-<title>`、`symbol-<title>-pin-N`（N = 一覧の順）、`symbol-<title>-rotation`、`inspector-rotate`、`symbol-<title>-rotate` は、そのまま。
- 絵は、一般的な回路記号（JIS/IEC 風の、教材でよく見る形）。ゲートは、MIL 記号（D 型の AND、盾型の OR、丸つきの NAND/NOR/NOT）。

### テスト（Claude）
- 単体テスト: 全種類について、ピンの数・座標（0/90/180/270）・外向きの方向・本体の長方形。既存の種類が、従来と同じ値であること。ピン同士の間隔が 50pt 以上。ピンが、本体の外側の境界上にあること。
- UI テスト: 新しい種類を、カテゴリごとに 1 回の起動で配置し、ピン数・識別子・回転を確認する（第1弾のカタログのテストを拡張。**起動の回数を増やさない**）。3 端子以上の記号への配線（複数ピンから別々の配線）、回転後の配線、同じシンボルの任意のピン同士が結べないこと、を確認する。
- ゲート時間は、今の約 5 分から、大きく増やさない（+1 分程度まで）。

- ブロック図型は、このタスクでは、変えない（次の 2A）。
