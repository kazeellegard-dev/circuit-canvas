# タスク: 倍率をスライダーで調整する（2026-10-03 の利用者の要望）

## 背景

右上の倍率の表示をタップすると、決まった 5 つの倍率（25 / 50 / 100 / 150 / 200%）から選ぶメニューが出ていた。利用者の要望で、スライダーを表示して、任意の倍率に調整できるようにする。上限と下限は、今のままとする。

あわせて、iPad 第 7 世代（iPadOS 18、10.2 インチ）では、メニューの項目が画面に収まらない問題があった。スライダーにすることで、この問題も解消する。

## 要件

1. 倍率の表示（`zoom-menu`）をタップすると、ポップオーバーでパネルを開く。パネルの中身は次のとおり。
   - 今の倍率（1% 単位）
   - スライダー（両端に、縮小・拡大のアイコンと、下限・上限の値）
   - 「100% に戻す」ボタン
2. **範囲:** ピンチと同じく、25%〜250%（`CanvasZoom.minimumScale` / `maximumScale`）とする。
3. **目盛り:** 対数にする。同じだけ動かすと、どこでも同じ比率で拡大・縮小する。100% は、スライダーの約 60% の位置になる。
4. **倍率の値:** 1% 単位に丸める。
5. **動き:**
   - スライダーを動かすと、その場で倍率が変わる。
   - 拡大・縮小の中心は、これまでのメニューと同じく、画面の中央とする（`setZoom`）。
6. **「100% に戻す」:** ちょうど 100% にする。すでに 100% のときは、押せない。
7. **使い方の説明（コーチマーク）:** 5 番目の文を、スライダーに合わせて直す。
8. **無効になるとき:** 編集モードや、キャンバス上での文字の編集中は、これまでどおり、倍率の表示を押せない。

## 受け入れ条件

- Z1: スライダーの両端が下限・上限になること、目盛りが対数であること、1% 単位になること、位置と倍率を変換して元に戻ること（単体テスト: `CanvasZoomTests`）
- Z2: スライダーで、メニューになかった倍率（例: 130%）に変えられる。両端は 25% と 250% になる。「100% に戻す」で、ちょうど 100% になる（UI テスト: `testZoomSliderAdjustsToAnyScaleBetweenTheLimits`）
- Z3: 端の近くまで移動した状態で、スライダーで拡大・縮小しても、画面の中央の位置がずれない（UI テスト: `testZoomSliderKeepsTheViewportCenterEvenWhenAlreadyPannedNearTheEdge`）
- Z4: ピンチや起動時の設定で、端数の倍率になっているときでも、「100% に戻す」で、ちょうど 100% になる（UI テスト: `testZoomResetLandsExactlyOn100AfterAPinch` / `testZoomResetLandsExactlyOn100FromAnInjectedStartingScale`）
