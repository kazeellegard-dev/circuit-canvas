# タスク（第5弾 5F）: シンボル配置・配線を格子（グリッド）に沿わせる

2026-09-29 のユーザー提案、および QA 回答（2026-09-29）より。

## 背景・狙い

現状は、シンボルの移動も配線の移動もかなり自由（ピクセル単位）にできてしまうため、微妙な配線の段差が生まれやすく、きれいに見せるには細かい手動調整が必要になっている。キャンバスにはすでに格子線があるので、配置・移動を格子に合わせる（スナップ）ことで段差を生まれにくくする。

## 要件（QA で確定）

- **格子の間隔**: 24pt → **15pt** に変更する。既存のシンボルの大きさ（60・120・30・90）と、ピンの位置（引き出し 15pt、ブロックのピン列の間隔）をすべて割り切れる値として選んだ。シンボルの位置を格子に合わせれば、ピンもすべて格子の上に来る。描画する格子線も同じ 15pt にする。
- **スナップのタイミング**: ドラッグ中は指に合わせて自由に動き、**指を離した瞬間**に最寄りの格子へ揃える。
- **対象**: シンボル・メモ・テキストの配置（タップ）と移動（ドラッグ、グループごとの移動を含む）。配線の線分の手動ドラッグ（線分の共通座標: 水平なら y、垂直なら x）。
- **ON/OFF**: 設定画面に「グリッドにスナップ」のトグルを追加する。既定は ON。端末ごとの設定（`@AppStorage("gridSnapEnabled")`）で、キャンバスの内容には含めない。

## 対象外・注意

- 既存の（格子に乗っていない）配置を一括で揃える移行処理は行わない。次に動かしたときに揃う。
- スナップは、そのドラッグと同じ Undo の 1 段にまとめる（スナップ単独で Undo 履歴を増やさない）。
