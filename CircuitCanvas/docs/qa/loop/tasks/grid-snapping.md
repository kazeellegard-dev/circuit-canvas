# タスク（第5弾 5F）: シンボル配置・配線を格子（グリッド）に沿わせる

2026-09-29 のユーザー提案、および QA 回答（2026-09-29）より。

## 背景・狙い

現状は、シンボルの移動も配線の移動もかなり自由（ピクセル単位）にできてしまうため、微妙な配線の段差が生まれやすく、きれいに見せるには細かい手動調整が必要になっている。キャンバスにはすでに格子線があるので、配置・移動を格子に合わせる（スナップ）ことで段差を生まれにくくする。

## 要件（QA で確定）

- **格子の間隔**: 24pt → **15pt** に変更する。既存のシンボルの大きさ（60・120・30・90）と、ピンの位置（引き出し 15pt、ブロックのピン列の間隔）をすべて割り切れる値として選んだ。シンボルの位置を格子に合わせれば、ピンもすべて格子の上に来る。描画する格子線も同じ 15pt にする。
- **スナップのタイミング**: ドラッグ中は指に合わせて自由に動き、**指を離した瞬間**に最寄りの格子へ揃える。
- **対象**: シンボル・メモ・テキストの配置（タップ）と移動（ドラッグ、グループごとの移動を含む）。配線の線分の手動ドラッグ（線分の共通座標: 水平なら y、垂直なら x）。
- **格子が優先**（2026-09-29 QA 回答）: 配線の線分を離したとき、近くの平行線（13pt 以内）へ揃える既存の「段差の直線化」よりも、格子へのスナップを優先する。5F 以前の格子外の配線では、数 pt の段差が残ることがある。隣の線が格子上にあれば、これまで通り 1 本にまとまる。
- **ON/OFF**: 設定画面に「グリッドにスナップ」のトグルを追加する。既定は ON。端末ごとの設定（`@AppStorage("gridSnapEnabled")`）で、キャンバスの内容には含めない。

## 対象外・注意

- 既存の（格子に乗っていない）配置を一括で揃える移行処理は行わない。次に動かしたときに揃う。
- スナップは、そのドラッグと同じ Undo の 1 段にまとめる（スナップ単独で Undo 履歴を増やさない）。

## 結果

2026-09-29、Codex レビュー round 3 で承認（blocker 0 / major 1 / minor 0 / 提案 0。3 回目以降は blocker のときだけ差し戻すルール）。フルスイートのゲート 132 件成功。round 3 の major も修正済み（下記）。

round 1 で修正した major（3件）:
- 背景のパン操作から始めた線分ドラッグ（短い線分）が、離してもスナップされなかった。こちらの終了処理でも `endSegmentDrag()` を呼ぶよう修正。
- 線分のスナップを、移動後の経路に差分を足すのではなく、開始時の経路に「最終移動量を格子に丸めた量」を適用する方式に変更（経路が簡略化されて線分の番号がずれる問題も解消）。
- 配線テストの 3pt 操作は、ジェスチャーの最小距離（4pt）未満でドラッグが起きていなかった。33pt の操作で、期待する格子線と一致することを検査し、OFF 時の対のテストも追加。

round 1 のテスト基盤の変更: スナップは既定 ON なので、5F 以前のテスト（格子外の正確な座標を検査している）が崩れる。全テストを `makeApp()` 経由で起動し、既定でスナップ OFF（`UITEST_GRID_SNAP=0`）にした。5F のテストだけが ON を指定する。

round 2 で修正した major（1件）: 近接整列（13pt 以内の平行線へ揃える直線化）が格子へのスナップを上書きしていた。ユーザー判断で「格子が優先」とし、離したときは `WireRouting.moved(..., alignToNeighbours: false)` で最寄りの格子線に置く。この検証中に、5F 以前からの不具合も見つけて修正: ドラッグ途中で直線化されると線分の当たり判定ビューが消え、ジェスチャーの `onEnded` が呼ばれず、`segmentDrag` が残ったままになっていた。ドラッグ中は開始時の経路で当たり判定を保つ。

round 3 で修正した major（1件）: 編集モードなどで移動が拒否されたドラッグでも、離したときにスナップして位置・配線が Undo なしで変わっていた。実際に動いた（ドラッグ開始位置の記録がある）要素だけをスナップするよう修正し、回帰テストを追加。

minor（テキストのドラッグの移動前後比較、水平・垂直の両方の検査、グループ移動と 1 回の Undo）は、いずれもテスト強化として対応済み。

補足: 設定画面のトグルのテストが失敗していた原因は、アプリではなくテスト側だった。`toggle.tap()` は行の中央（ラベル）を押すため、iPad ではスイッチが切り替わらない。スイッチ部分（右端）を押すよう修正。
