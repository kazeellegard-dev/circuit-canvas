# タスク（第5弾 5B）: キャンバス移動を専用モード・二本指ドラッグに限定

2026-09-29 のユーザーフィードバックより。

## 背景

今は、シンボル・配線以外の場所を指1本でドラッグすると、キャンバスが移動する。配線の線分をつかもうとした際の判定がシビアで、意図せずキャンバスが動いてしまうことが多い。

## 要件

- キャンバス移動（パン）は、次の2通りのみに限定する。
  1. キャンバス上の専用アイコン（四方に矢印が伸びるアイコン）をタップして「キャンバス移動モード」に入っているときの、指1本のドラッグ。
  2. モードに関わらず、常に使える、二本指でのドラッグ。
- 上記以外（通常時の指1本のドラッグ）は、キャンバスを動かさない。配線の線分をつかむドラッグ（既存の判定）は、これまで通り指1本で機能する。
- キャンバス移動モードは、他のツール（選択・配線・シンボル追加・メモ追加）と同様、排他的なモードとして良い。

## 受け入れ条件

1. 通常時、配線のない場所を指1本でドラッグしても、キャンバスは動かない。
2. 専用アイコンをタップしてキャンバス移動モードに入ると、指1本のドラッグでキャンバスが動く。
3. モードに関わらず、二本指のドラッグでキャンバスが動く。
4. 配線の線分を指1本でドラッグする操作（既存機能）は、引き続き動作する。

## 対象外・注意

- ピンチでの拡大縮小（既存）は変更しない。
