# タスク（第4弾 4B）: 設定（名称・説明・リセット）

## 要件

- ツールバー（インスペクタ「確認」ボタンの近く）に、設定（歯車アイコン）の入り口を追加する。
- 設定画面（シート）に、以下を置く：
  - **キャンバス名称**: テキストフィールド。変更すると、画面上部のタイトル（今は固定で「Circuit Canvas」）が変わる。
  - **説明欄**: 複数行のテキスト。既定は空欄。
  - **リセット**: キャンバスの内容（シンボル・配線・付箋）を全て消し、まっさらな状態にする。押しても即実行しない。「本当にリセットしますか？元に戻せません」の確認を出し、確定した場合のみ実行する。誤操作を避けるため、他の項目からは離した位置に置く（例: リストの一番下、区切りを空けて）。

## 受け入れ条件（QA がこれで判定する）

1. 設定（歯車）を押すと、設定画面が開く。
2. キャンバス名称を変更すると、画面上部のタイトルが変わる。
3. 説明欄に文字を入力できる（既定は空欄）。
4. リセットを押すと、確認が出る。取り消すと何も変わらない。確定すると、シンボル・配線・付箋が全て消える。

## 対象外・注意

- 名称・説明・リセットの内容を、アプリ再起動後も保つ必要はない（今回は実行中のみでよい。永続化は将来検討）。
