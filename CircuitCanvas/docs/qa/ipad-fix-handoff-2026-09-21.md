## 修正詳細

### 1. 座標系（F1〜F3）

- パンとキャンバスタップのジェスチャーを、拡大縮小されないエディタ全体へ移した。
- `editorViewport` という固定座標系でパンの移動量を取得し、画面座標のオフセットとして適用する。
- シンボルと付箋のドラッグは、拡大対象内のローカル移動量をそのまま使う。以前の `canvasScale` による二重補正は削除した。
- 付箋のドラッグジェスチャーは `NoteCard` の内部ではなく、`.position` の後に付与した。
- パン可能範囲を制限し、キャンバスが完全に画面外へ消えないようにした。
- キャンバス論理サイズを `2400 x 1800` pt に広げ、50%表示でも操作できる余白を確保した。

### 2. 初期配線データ（F4）

- Temperature → MCU 配線の終点を `(295, 275)` から `(295, 250)` へ修正した。
- `(295, 250)` は初期状態の Main MCU 左ピンの座標である。

### 3. 倍率表示（F5）

- キャンバス内カプセルの表示を左上から右上へ移した。
- 表記は `倍率 100%` のように、現在値を常時表示する。
- ツールバー内の倍率ボタンは、引き続き100%・初期位置へのリセット操作に使う。

## Claude Code が実施する再テスト

コードは変更せず、各項目を「成功」「失敗」「確認不能」で記録すること。失敗時は、再現手順・実際の挙動・期待する挙動・スクリーンショットを残すこと。

### A. ビルドと起動

1. iPad Pro 11-inch (M5) / iOS 26.5 向けに Debug ビルドする。
2. アプリを起動する。
3. 下部にシンボルライブラリ、キャンバス右上に `倍率 100%` が表示されることを確認する。

### B. パンの追従量（F1、項目3・10）

各倍率 50% / 100% / 175% / 250% で、空白部分を画面上で100ptドラッグする。

- 受け入れ条件: キャンバス全体の画面上の移動量が100pt（±数pt）であること。
- 受け入れ条件: 50%で100ptドラッグしても、キャンバス全体が消えないこと。
- 受け入れ条件: 50%表示でキャンバス外側の白い領域に触れても、ズーム以外の不自然な状態にならないこと。
- 追加確認: パン後に倍率リセットで100%・初期位置へ戻ること。

### C. シンボルのドラッグ追従量（F2、項目6）

各倍率 50% / 100% / 175% / 250% で、`24 V → 5 V` を画面上で100ptドラッグする。

- 受け入れ条件: シンボルの画面上の移動量が100pt（±数pt）であること。
- 受け入れ条件: シンボル操作中にキャンバス全体がパンしないこと。

### D. 付箋のドラッグ追従量（F3、項目7・8）

各倍率 50% / 100% / 175% / 250% で、`R12を変更` の付箋を画面上で100ptドラッグする。

- 受け入れ条件: 付箋の画面上の移動量が100pt（±数pt）であること。
- 受け入れ条件: 関連付けの引出し線が付箋移動に追従すること。
- 受け入れ条件: 付箋操作中にキャンバス全体がパンしないこと。

### E. 初期配線の追従（F4、項目9）

1. Main MCU を上方向へ100pt移動する。
2. 3本の既存配線を確認する。

- 受け入れ条件: Temperature → MCU を含む3本すべてが、移動後の対象ピンに接続されたまま追従すること。
- 受け入れ条件: 配線端点が取り残されないこと。

### F. 倍率表示（F5、項目4・5）

1. ピンチアウト／ピンチインを行う。
2. 50% / 100% / 175% / 250% の各状態で倍率表示を確認する。
3. 倍率リセットを実行する。

- 受け入れ条件: 右上に現在の倍率が常時見えること。
- 受け入れ条件: ズーム範囲が50〜250%に制限されること。
- 受け入れ条件: リセット後に100%・初期位置へ戻ること。

## 実装者による自己確認

- `xcodebuild` による iPad シミュレーター向けビルドは、各修正後に成功した。
- 最新ビルドをシミュレーターで起動し、初期のシンボル／付箋／接続済み状態と、右上の `倍率 100%` 表示を確認した。
- F4 は初期配線の端点が Main MCU 左ピン `(295, 250)` と一致することをコード上で確認した。
