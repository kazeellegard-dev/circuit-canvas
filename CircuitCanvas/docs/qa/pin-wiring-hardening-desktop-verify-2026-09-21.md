- 選択ツールでピンをタップした前後の差分は、なし（ピンは何も起こさない）。

## 新規指摘

### H1（minor）: 操作ヒントが倍率とパンに追従し、画面外へ出る

- 再現手順:
  1. アプリを起動し、ピンチで 175% に拡大する。
  2. 配線ツールを選び、Temperature の右ピンをタップする。
  3. キャンバスを 100pt 左・100pt 上へパンする。
- 実際の挙動:
  - 175% では、ヒントが約 1.75 倍の大きさで表示される（`03`）。
  - パンすると、ヒントがキャンバスと一緒に動き、画面外へ出て見えなくなる（`02`）。250% でパンしたときは、ヒントが左上の端にはみ出した。50% では小さく表示される。
- 期待する挙動: ヒントは、倍率ラベルと同様に、ビューポートに固定して、倍率・パンに関係なく同じ大きさ・位置で表示される。
- 原因の推測（コードを読んだ範囲）: `ContentView.swift:191-194` の `hint(...)` が、`scaleEffect` / `offset` のかかった `canvasContent` の中で描画されている。倍率ラベルは、以前の修正でビューポート側（`.overlay(alignment: .topTrailing)`）へ移されている。
- 影響: 配線ツールだけでなく、付箋・シンボル配置・関連付けのヒント（191〜194 行の 4 種）にも同じ。
- 証跡: `pin-wiring-hardening-desktop-02-hint-missing-175pct-panned.png`、`pin-wiring-hardening-desktop-03-hint-scaled-175pct.png`
- 受け入れ条件案: 50 / 100 / 175 / 250% とパン後のすべてで、ヒントが同じ大きさで、左上に常時表示される。

## 仕様未定の挙動の観察（失敗にしない）

| 挙動 | 観察結果 |
|---|---|
| 始点と同じピンをもう一度タップ | 無視される。始点の選択は維持され、配線は追加されない。 |
| 空白のキャンバスをタップ | ピンから約 40pt 離れた空白（CAN 左ピンの真下）をタップすると、最近傍のピンが終点として選ばれ、配線が追加された。約 70pt を超える遠い空白は無視され、始点の選択は維持された。 |
| 同じシンボルの左右ピンを接続 | 配線が追加される（3 → 4）。配線がシンボル本体の裏に隠れ、画面には何も現れない。 |
| シンボル本体（ピン以外）をタップ | 中心から 20pt 左（左ピンから 55pt）の本体上のタップは、何も起きない。最近傍ピンの選択は、シンボルの外の空白でだけ働く。 |
