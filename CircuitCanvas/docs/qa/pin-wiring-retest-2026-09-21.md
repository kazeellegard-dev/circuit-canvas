# CircuitCanvas ピン配線機能の確認結果（2026-09-21）

## 対象

- 修正コミット: `32547df Add interactive pin wiring`
- 環境: iPad Pro 11-inch (M5) / iOS 26.5 シミュレーター

## 実装

- 配線ツール中、シンボルの左右ピンを個別にタップして始点・終点を選択できる。
- 始点ピンはアクセントカラーで強調される。
- 2つ目のピンを選ぶと直交配線を追加して、選択ツールへ戻る。
- 同じ2ピン間の重複配線は追加しない。

## 再テスト

UIテスト `testWireToolConnectsTwoSymbolPins()` を実行し、成功した。
